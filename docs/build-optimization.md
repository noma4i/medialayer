# Проверка release-сборки

Объект MediaLayer без владельца освобождается через Cleaner.
Тест удерживает объект до завершения проверяемой операции и вызывает close в finally.
Это сохраняет время жизни владельца при изменении локальных переменных оптимизатором.

UniFFI регистрирует native-методы через Native.register.
R8 сохраняет их имена, структуры JNA и методы callback.
Обычные модели не требуют сохранения всего пакета.

MediaSource допускает изменяемые реализации и Map заголовков.
UniFFI создаёт MediaItem с изменяемыми полями.
Не объявляй эти типы неизменяемыми через stability-конфиг.
MediaImage, MediaVideo и MediaAudio допускают пропуск композиции при включённом strong skipping.
